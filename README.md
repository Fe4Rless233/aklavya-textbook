# aklavya-textbook

A basic static site for hosting and viewing textbook PDFs.

## Usage

1. Put your PDF files inside `/pdfs`.
2. Update the `textbooks` list in `/script.js` with the tab title and file path.
3. Open `index.html` in a browser.

Example entry:

```js
{ title: 'Math Textbook', file: 'pdfs/math-textbook.pdf' }
```
